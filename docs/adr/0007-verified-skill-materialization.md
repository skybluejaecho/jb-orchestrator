# ADR 0007: 검증형 스킬 materialization과 content-addressed cache

- 상태: 채택
- 날짜: 2026-09-01

## 배경

스킬 카탈로그 등록은 실행 가능한 파일을 설치하는 작업이 아니다. 워커가 로컬 경로,
Git 저장소 또는 압축 파일에서 스킬을 가져올 때 등록 시점의 내용과 실제 실행 내용이
달라질 수 있고, 경로 이탈·심볼릭 링크·악성 압축 파일 같은 위험도 존재한다.

## 결정

워커는 executor를 호출하기 전에 다음 순서로 스킬을 materialize한다.

1. 실행 스냅샷에 고정된 정확한 스킬 버전과 digest를 읽는다.
2. 소스를 임시 디렉터리로 가져온다. 로컬 소스는 설정된 루트 아래로 제한하고,
   원격 Git/압축 소스는 허용 목록의 호스트만 사용한다. Git은 revision을 반드시
   고정한다.
3. 압축 해제 시 경로 이탈, 심볼릭 링크, 특수 파일과 크기 제한 위반을 거부한다.
4. 상대 POSIX 파일 경로와 파일 바이트를 정렬한 canonical SHA-256 digest를 계산한다.
5. 등록된 digest 및 entrypoint와 일치할 때만 digest 기반 캐시 디렉터리로 원자적으로
   이동한다.
6. executor에는 등록 URI가 아니라 검증된 캐시의 entrypoint 경로를 전달한다.

기존 캐시도 매번 digest를 재검증한다. 따라서 캐시가 외부에서 변경되면 실행을
거부한다. 동일 digest를 동시에 준비하는 워커들은 최종 캐시를 공유하고, 각 staging
디렉터리는 성공·실패 여부와 무관하게 정리한다.

## 결과

- DB의 스킬 메타데이터와 실행 파일 사이의 정합성이 digest로 성립한다.
- 등록만으로 임의 네트워크 접근이나 코드 실행이 발생하지 않는다.
- executor 구현은 검증·다운로드 로직 없이 준비된 경로만 소비한다.
- 캐시는 내용 기준으로 재사용할 수 있으나, 패키지별 의존성 설치나 컨테이너 mount는
  향후 executor adapter의 책임으로 남는다.
