# ADR 0013: 외부 실행 관찰은 영속 원장을 기준으로 제공한다

## 상태

승인됨

## 배경

Jarvis와 다른 클라이언트는 OpenClaw 같은 외부 런타임에서 수행되는 작업의 현재 상태를
표시해야 한다. 런타임에 직접 질의하면 일시적인 연결 문제와 프로세스 재시작 때문에
JB Orchestrator의 워크플로 상태와 다른 결과를 보여줄 수 있다.

## 결정

- PostgreSQL의 `external_executions`를 외부 실행 상태의 단일 기준으로 사용한다.
- REST API는 외부 실행 단건 조회와 필터 가능한 목록 조회를 제공한다.
- 준비, 수락, 종료 상태 전이는 외부 실행 원장 변경과 같은 트랜잭션에서 도메인 이벤트를
  기록한다.
- 이벤트에는 식별자와 상태만 담고, 큰 종료 결과는 외부 실행 원장에서 조회한다.
- 초기 클라이언트 연동은 폴링을 사용한다. SSE는 동일한 상태 이벤트를 전달하는 별도
  전송 계층으로 후속 추가한다.

## 결과

클라이언트는 외부 런타임 구현을 몰라도 안정적으로 상태를 조회할 수 있다. 폴링과 향후
SSE가 같은 영속 상태를 가리키므로 서로 다른 화면이나 재연결 과정에서도 정합성을 유지할
수 있다. 실시간 스트림과 API 인증은 후속 작업의 범위다.
