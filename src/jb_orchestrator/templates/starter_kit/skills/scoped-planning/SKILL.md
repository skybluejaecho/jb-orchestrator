# Scoped planning

Read the original request and repository context before proposing work.

1. State the intended outcome and the boundaries that must not change.
2. Identify affected components and durable contracts.
3. Divide the work into independently verifiable steps.
4. Record assumptions, risks, and acceptance checks.
5. Return only the structured result required by the active phase contract.

Do not implement code during a planning-only phase.
